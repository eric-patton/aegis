# Aegis 1.0.0

Aegis 1.0 is the first complete Windows x64 release of the deterministic terminal RPG.

This release includes:

- Four connected countries with travel, weather, regional sites, work, trade, and rest.
- A complete turn-based combat, equipment, skill, magic, companion, faction, and
  consequence foundation.
- Deterministic world generation pinned as generator version 1.
- Append-only campaign journals using save version 99.
- Local simulation, journey, pilot, and world-generation verification tools.
- A self-contained Windows x64 Native AOT executable.

The release contains no installer, updater, telemetry, network dependency, cloud save,
automatic save migration, or code signing.

The final packaged campaign playthrough is a separate human signoff gate. Consult the
release audit distributed with the source project for candidate status.
